# opengame-audio

Make a browser game sound finished. Covers sound from the first press on every device, audio QA without ears, a person listening before shipping, the player's shot leading the mix, a weapons limiter, no delay, a quiet player body, harshness and loudness gates, sounds heard at range and played whole, loops, generated takes, voice casting and buses.

It is one of the [OpenGame](https://opengame.io) agent skills, which teach a coding agent such
as Claude Code, Codex, Cursor or OpenCode to build a browser game and put it online.

## Install

```bash
npx skills add opengamehq/audio
```

The skill installs under its own name, `opengame-audio`. Every OpenGame skill, each under its own
name, installs from [opengamehq/opengame](https://github.com/opengamehq/opengame):

```bash
npx skills add opengamehq/opengame
```

How the skills fit into making and shipping a game is at [docs.opengame.io](https://docs.opengame.io).
